# JP's Codeless Macro Tool

[한국어](README.md) | **English**

**Automate repetitive mouse clicks and keyboard input without coding.**

JP's Codeless Macro Tool is a free macro tool for Windows. Record your actions or add steps such as clicks and text input to build your own automation sequence.

**[Install from Microsoft Store](https://apps.microsoft.com/detail/9NXX9L2ZW52W)** | **[User manual](manual/en/README.md)** | **[What's new](release_notes/v1.9.0.en.md)**

## What you can do

- Click the same position repeatedly or visit a sequence of coordinates.
- Enter frequently used text, key combinations, or values that change on each repetition.
- Find images or read on-screen text with OCR to decide the next action.
- Combine conditions and loops, and reuse common actions across macros.

## Install and update

1. Open the [Microsoft Store product page](https://apps.microsoft.com/detail/9NXX9L2ZW52W).
2. Install and launch **JP's Codeless Macro Tool**.
3. Receive subsequent updates through Microsoft Store.

The Store release is **v1.9.0**. The app supports Korean, English, Japanese, Simplified Chinese, Traditional Chinese, Spanish, Brazilian Portuguese, German, and French interfaces. Configure language and hotkeys in [Options](manual/en/09-options-and-hotkeys.md).

### Need a portable version?

The [portable ZIP on GitHub Releases](https://github.com/plcmanjp/codeless-macro-tool/releases/latest) is **frozen at v1.4.0**. Features and fixes from v1.4.1 onward are provided in the Store edition. Install the Store edition for current features. If you specifically need the portable edition, download `JPsCodelessMacroTool.zip` from the release, extract it, and run `JPsCodelessMacroTool.exe`.

## Create your first macro

1. **Create a project.** See [Basic editing and file management](manual/en/02-editing-and-files.md) for creating and saving projects.
2. **Add actions.** [Record](manual/en/03-recording-and-playback.md) mouse and keyboard actions or start with [Sample steps](manual/en/12-sample-steps.md).
3. **Review the order and delays, then save.** Test a few short actions first.
4. **Prepare the target app and play.** The default play hotkey is `F9`; stop is `F10`. If you changed them, check your current Options settings.

Ordinary playback controls the real mouse and keyboard. Keep the target window and screen layout in place, and stop if the macro behaves unexpectedly. [Background input](manual/en/14-background-input.md) support varies by target application and input mode.
