## JP's Codeless Macro Tool user manual

This is the full manual index. If you are new to the app, read the first guides in numerical order. Reference versions differ by chapter, as listed below.

## Quick start

1. Read **Overview** to see what the app can do.
2. Read **Basic editing and file management** to create projects, edit steps, and save.
3. Read **Recording and playback** to capture actions and run them.
4. Continue with conditions, loops, pointers, variables, regular expressions, image search, sample steps, or favorites as needed.
