# JP's Codeless Macro Tool

**한국어** | [English](README.en.md)

**반복하는 마우스 클릭과 키보드 입력을 코딩 없이 자동화하세요.**

JP's Codeless Macro Tool은 Windows용 무료 매크로 도구입니다. 직접 조작한 동작을 녹화하거나, 클릭과 입력 같은 동작을 스텝으로 추가해 나만의 자동화 순서를 만들 수 있습니다.

**[Microsoft Store에서 설치하기](https://apps.microsoft.com/detail/9NXX9L2ZW52W)** | **[사용자 매뉴얼](manual/README.md)** | **[업데이트 내역](release_notes/v1.9.0.md)**

## 이런 작업에 사용할 수 있습니다

- 같은 위치를 반복해서 클릭하거나 여러 좌표를 차례대로 클릭하기
- 자주 쓰는 문장, 키 조합, 반복마다 달라지는 값을 자동으로 입력하기
- 화면에서 이미지를 찾거나 OCR로 글자를 읽어 다음 동작 결정하기
- 조건과 반복을 조합하고, 공통 작업을 저장해 여러 매크로에서 재사용하기

## 설치와 업데이트

1. [Microsoft Store 상품 페이지](https://apps.microsoft.com/detail/9NXX9L2ZW52W)를 엽니다.
2. **JP's Codeless Macro Tool**을 설치하고 실행합니다.
3. 이후 업데이트도 Microsoft Store를 통해 받습니다.

Store 배포 버전은 **v1.9.0**입니다. 한국어, 영어, 일본어, 중국어 간체, 중국어 번체, 스페인어, 브라질 포르투갈어, 독일어, 프랑스어 UI를 지원합니다. 언어와 단축키는 [옵션](manual/9.%20옵션과%20단축키.md)에서 설정할 수 있습니다.

### 설치 없이 실행하는 포터블이 필요한가요?

[GitHub Releases의 포터블 ZIP](https://github.com/plcmanjp/codeless-macro-tool/releases/latest)은 **v1.4.0에서 제공이 멈췄습니다.** v1.4.1 이후 기능과 수정은 Store판에 반영됩니다. 최신 기능을 사용하려면 Store판을 설치하세요. 포터블이 꼭 필요하다면 릴리스의 `JPsCodelessMacroTool.zip`을 내려받아 압축을 풀고 `JPsCodelessMacroTool.exe`를 실행합니다.

## 첫 매크로 만들기

1. **새 프로젝트를 만듭니다.** [기본 편집과 파일관리](manual/2.%20기본%20편집과%20파일관리.md)에서 프로젝트와 저장 방법을 확인하세요.
2. **동작을 추가합니다.** [녹화](manual/3.%20녹화와%20재생.md)로 마우스와 키보드 동작을 기록하거나, [샘플 스텝](manual/12.%20샘플%20스텝.md)을 불러와 시작할 수 있습니다.
3. **실행할 순서와 대기 시간을 확인하고 저장합니다.** 처음에는 짧은 동작 몇 개로 시험하세요.
4. **대상 프로그램을 준비하고 재생합니다.** 기본 재생 단축키는 `F9`, 중지는 `F10`입니다. 단축키를 변경했다면 옵션에서 현재 설정을 확인하세요.

일반 재생은 실제 마우스와 키보드를 조작합니다. 실행 중에는 대상 창과 화면 배치를 유지하고, 예상과 다른 동작이 보이면 중지하세요. [백그라운드 입력](manual/14.%20백그라운드%20입력.md)은 대상 프로그램과 입력 방식에 따라 지원 범위가 다릅니다.
