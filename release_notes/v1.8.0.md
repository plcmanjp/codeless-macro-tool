# v1.8.0

출시일: 2026-08-04

## 새로운 기능

- **6개 언어 UI 지원**: 기존 한국어와 영어에 일본어, 중국어 간체, 중국어 번체, 스페인어를 추가했습니다. 옵션에서 원하는 언어를 직접 선택하거나 `자동`을 선택해 Windows 표시 언어에 맞출 수 있습니다.
- **표준 버튼까지 같은 언어로 표시**: 확인, 취소, 예, 아니요처럼 Windows 대화상자에 쓰이는 기본 버튼도 선택한 앱 언어에 맞춰 표시합니다.

## 개선 사항

- **언어 선택의 안전한 적용**: 언어 변경은 저장 후 다시 시작할 때 전체 화면에 일관되게 적용됩니다. 번역 파일의 일부 문구를 찾지 못해도 해당 항목은 한국어로 표시되어 작업을 계속할 수 있습니다.
- **긴 번역 문구의 가독성 개선**: 버튼, 표 머리글, 입력 안내와 좌표 배열 창이 현재 표시 언어의 문구 길이에 맞춰 자동으로 폭을 조절합니다.
- **기존 작업 데이터 보존**: 언어를 바꿔도 기존 프로젝트, 즐겨찾기, 매크로에 입력한 텍스트와 OCR 인식 언어는 변경하거나 번역하지 않습니다.

> 기존 프로젝트와 설정은 별도 변환 없이 그대로 사용할 수 있습니다. 앱의 표시 언어만 확장되며 매크로 실행 데이터 형식은 바뀌지 않습니다.
