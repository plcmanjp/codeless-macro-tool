# v1.8.1

## 버그 수정

- **일본어 주석 버튼의 단축키 표기 수정**: 일본어로 표시할 때 주석 버튼에 세미콜론이 두 개(`;;`)로 나와 실제 단축키를 잘못 안내하던 문제를 고쳤습니다. 이제 실제 단축키와 같은 `;` 하나로 표시됩니다.
- **업데이트 내용에서 빠지던 항목 표시**: "최근 변경내용" 창에 버그 수정 항목이 표시되지 않던 문제와, 영어로 볼 때 새로운 기능 항목이 통째로 빠지던 문제를 함께 고쳤습니다.

> 이번 버전은 화면에 표시되는 문구만 고칩니다. 기존 프로젝트, 즐겨찾기, 매크로 파일과 설정은 그대로 사용할 수 있습니다.
