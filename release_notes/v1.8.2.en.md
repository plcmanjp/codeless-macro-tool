# v1.8.2

Date: 2026-08-09

## Improvements

- **Clearer displayed text**: Replaced long dash and middle-dot style symbols in on-screen guidance with ordinary punctuation that fits each sentence.

  Messages are easier to read and less likely to look like broken or list-style text.
- **Regression prevention for displayed text**: Added automated checks for source strings, translation catalogs, and displayed values so the same text issue does not return.
- **Macro recording restored**: Fixed an issue where recording keyboard and mouse input could produce no steps in the latest input handling environment.

> This release improves displayed text, recording reliability, and validation.
> Existing projects, favorites, macro files, settings, and saved data formats remain unchanged.
