# v1.8.2

출시일: 2026-08-09

## 개선 사항

- **표시 문구 가독성 개선**: 화면에 표시되는 안내 문장에서 긴 대시와 가운데점 계열 기호를 문맥에 맞는 일반 문장부호로 정리했습니다.

  문장이 끊겨 보이거나 목록처럼 오해되는 부분을 더 자연스럽게 읽을 수 있습니다.
- **표시 문구 재발 방지**: 같은 표시 문제가 다시 들어오지 않도록 소스 문자열, 번역 카탈로그, 실제 표시값을 확인하는 자동 검사를 추가했습니다.
- **매크로 녹화 복구**: 최신 입력 처리 환경에서 키보드와 마우스 입력을 녹화해도 스텝이 생성되지 않던 문제를 수정했습니다.

> 이번 버전은 표시 문구, 녹화 안정성과 검사 절차를 개선합니다.
> 기존 프로젝트, 즐겨찾기, 매크로 파일, 설정과 저장 데이터 형식은 변경하지 않습니다.
