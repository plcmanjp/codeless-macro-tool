# v1.8.0

Release date: 2026-08-04

## New Features

- **Six-language user interface**: Japanese, Simplified Chinese, Traditional Chinese, and Spanish join the existing Korean and English interface. Pick a language directly in Options, or choose `Auto` to follow the Windows display language.
- **Localized standard buttons**: Common Windows dialog buttons such as OK, Cancel, Yes, and No now follow the selected application language.

## Improvements

- **Safe language switching**: A language change applies consistently across the whole interface after you save and restart. If a translation file is missing an entry, only that text falls back to Korean so you can keep working.
- **Better readability for longer text**: Buttons, table headers, input hints, and the coordinate array window size themselves to the text length of the current display language.
- **Existing work is preserved**: Changing the language never converts or translates your projects, favorites, text typed into macros, or the OCR recognition language.

> Existing projects and settings continue to work without any conversion. Only the display language expands; the macro execution data format is unchanged.
