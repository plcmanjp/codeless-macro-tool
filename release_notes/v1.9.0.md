# v1.9.0

출시일: 2026-08-11

## 새로운 기능

- **9개 언어 UI 지원**: 기존 한국어, 영어, 일본어, 중국어 간체, 중국어 번체, 스페인어에 브라질 포르투갈어, 독일어, 프랑스어를 추가했습니다.
- **Windows 표시 언어 자동 선택 확대**: 브라질 포르투갈어, 독일어, 프랑스어 Windows 환경에서 해당 UI를 자동으로 선택합니다. 옵션에서 원하는 언어를 직접 선택할 수도 있습니다.

## 개선 사항

- **긴 번역 문구 레이아웃 개선**: 독일어와 프랑스어의 긴 버튼 문구도 잘리지 않도록 What's New 창과 정규식 추출 화면의 버튼 폭을 내용에 맞춰 조정했습니다.
- **다국어 품질 검사 확대**: 8개 번역 카탈로그의 1,044개 문구와 9개 언어의 전체 화면을 100%, 125%, 150% 배율에서 검사하는 자동 회귀를 추가했습니다.

> 기존 프로젝트, 즐겨찾기, 매크로 파일, 설정과 저장 데이터 형식은 변경하지 않습니다.
> 브라질 포르투갈어는 브라질 Windows 환경에서 자동 선택되며, 포르투갈 Portuguese 환경은 영어 UI를 유지합니다.
