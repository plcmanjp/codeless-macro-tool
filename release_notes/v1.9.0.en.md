# v1.9.0

Date: 2026-08-11

## New features

- **Nine display languages**: Added Brazilian Portuguese, German, and French to the existing Korean, English, Japanese, Simplified Chinese, Traditional Chinese, and Spanish interfaces.
- **Expanded Windows display language detection**: The app now selects Brazilian Portuguese, German, or French automatically on matching Windows environments. You can also choose any supported language in Options.

## Improvements

- **Better layouts for longer translations**: Updated the What's New and regex extraction buttons to size themselves from their content, preventing clipping in longer German and French labels.
- **Expanded multilingual quality checks**: Added full checks for 1,044 strings in each of the eight translation catalogs and all-screen layout regression across nine languages at 100%, 125%, and 150% scaling.

> Existing projects, favorites, macro files, settings, and saved data formats are unchanged.
> Brazilian Portuguese is selected automatically only for Brazilian Windows environments. European Portuguese environments continue to use English.
